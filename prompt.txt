================================================================================
INTERVIEW PREPARATION PORTAL — MASTER PROMPT
================================================================================
Use this prompt + paste the Job Description below to generate a complete,
production-ready, multi-page interview preparation website.
================================================================================

ROLE:
You are a senior full-stack developer and interview prep expert. Your job is to
build a premium, multi-page, static interview preparation website based on the
Job Description (JD) provided at the end of this prompt.

================================================================================
STEP 1: ANALYZE THE JOB DESCRIPTION
================================================================================

Read the JD carefully and extract:

1. TECHNICAL SKILLS — List every technology, tool, and framework mentioned.
   Group them into categories (e.g., Cloud, Database, ETL, BI, Programming).

2. DOMAIN KNOWLEDGE — Identify the industry/domain (e.g., NBFC, Banking,
   E-commerce, Healthcare). Extract domain-specific terminology and concepts.

3. EXPERIENCE LEVEL — Note the years of experience and seniority level.
   This determines the depth of questions (junior = definitions, senior = 
   architecture decisions, trade-offs, debugging scenarios).

4. RESPONSIBILITIES — List the key day-to-day responsibilities. These become
   the "what would you actually do" interview scenarios.

5. SOFT SKILLS — Note collaboration, communication, or leadership mentions.
   These feed into the behavioral/resume defense module.

================================================================================
STEP 2: GENERATE THE MODULE MAP
================================================================================

Based on the JD analysis, create these page types:

A. STUDY MODULES (one HTML page per major skill cluster):
   - Each module covers 3-5 subtopics with deep educational content
   - Each subtopic has: theory explanation, tables, code examples, key tips
   - Each subtopic has: 3+ Q&A pairs (click-to-reveal accordion style)
   - Each subtopic has: a "Mastered" checkbox for progress tracking

   Example module breakdown for a Data Engineer JD:
   - Module 1: Cloud Platform & Data Warehouse (AWS Redshift)
   - Module 2: Domain Knowledge (NBFC Housing Finance)
   - Module 3: SQL & Database Optimization
   - Module 4: Orchestration (Apache Airflow)
   - Module 5: BI & Visualization (Tableau)
   - Module 6: Behavioral / Resume Defense
   - Module 8: PySpark Core & Optimization
   - Module 9: Databricks & Delta Lake

B. INTERVIEW QUESTION BANK (one HTML page):
   - Organized by topic categories
   - 10-20 questions per category
   - Senior-level: focus on "why", trade-offs, debugging, architecture
   - Each answer includes: explanation, code snippets, comparison tables,
     and "what to say in the interview" tips
   - Domain-specific scenarios woven into every answer

C. BEHAVIORAL / RESUME DEFENSE (one HTML page):
   - Flashcard-style Q&A for common behavioral questions
   - STAR method script blocks
   - Domain transition framing (if applicable)
   - "Tell me about yourself" script customized for the JD

STEP 6: JAVASCRIPT ENGINE
================================================================================

The script.js must handle ALL of these features:

1. THEME TOGGLE — Dark/light mode with localStorage persistence
2. NAVBAR — Scroll shadow, mobile hamburger menu, active link highlighting
3. COUNTDOWN TIMER — Countdown to interview date (auto-detect next Wednesday 10AM)
4. PROGRESS TRACKING — Checkbox state saved to localStorage, SVG ring % updates
5. Q&A ACCORDION — Click to expand/collapse with smooth max-height animation
6. REVEAL BUTTONS — Click to show SQL solutions (toggle hidden content)
7. FLASHCARDS — Click front to expand back panel
8. CODE COPY — Copy code block content to clipboard with "Copied!" feedback
9. SCROLL ANIMATIONS — IntersectionObserver to fade-in sections on scroll
10. SMOOTH SCROLL — Anchor link smooth scrolling

Key implementation detail: Use max-height animation pattern for all
expand/collapse interactions. Set max-height to 0 when collapsed and to
element.scrollHeight when expanded. This provides smooth CSS transitions.

Update TOTAL_CHECKBOXES constant to match the actual number of mastery
checkboxes across ALL module pages.

STEP 7: CONTENT GENERATION RULES
================================================================================

ANSWER DEPTH (based on experience level in JD):
- 0-2 years:  Definition + simple example + one-liner tip
- 3-5 years:  Concept + code example + comparison table + common mistake
- 5+ years:   Architecture decision + trade-off analysis + production debugging
              scenario + "what I actually did" narrative + domain-specific context

DOMAIN INTEGRATION:
- Every technical answer must include a domain-specific example from the JD
- e.g., For NBFC: "loan_id", "DPD buckets", "NPA classification"
- e.g., For E-commerce: "order_id", "cart abandonment", "inventory sync"

QUESTION STYLE:
- Mix these question types in every Q&A section:
  1. "Explain X" — conceptual understanding
  2. "Write SQL to..." — hands-on coding
  3. "Your pipeline fails because..." — debugging scenario
  4. "Compare X vs Y" — trade-off analysis (use tables)
  5. "How would you design..." — architecture/system design

TABLES:
- Use comparison tables heavily (feature vs feature)
- Use tables for classification data (e.g., DPD buckets, node types)
- Always use <table class="data-table"> with proper thead/tbody

CODE:
- Use syntax-highlighted code blocks for all SQL, Python, YAML, JSON
- Add meaningful comments in code
- Use domain-specific table/column names in examples
- Always show the code-copy button

INTERVIEW TIPS:
- Add "💡 Interview Tip" callouts after complex topics
- Add "⚠️ Critical" warnings for common mistakes
- Include "what to say" verbatim scripts for behavioral questions
